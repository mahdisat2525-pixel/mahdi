# shop 2 mahdisat V6

نسخة محدثة من تطبيق تسيير محل الإلكترونيات.

## جديد في V6
- شعار shop 2 mahdisat أصبح أيقونة التطبيق.
- شاشة افتتاحية احترافية تحمل الشعار قبل الدخول للتطبيق.
- الحفاظ على وظائف V5: المبيعات، المنتجات، IMEI/الرقم التسلسلي، الزبائن والديون، الصيانة، الصندوق، التقارير، الباركود، الفواتير، والنسخ الاحتياطي والاسترجاع.

## بناء APK
افتح المشروع في Android Studio ثم Build > Build APK(s).
الملف الناتج عادة في `app/build/outputs/apk/debug/app-debug.apk`.
